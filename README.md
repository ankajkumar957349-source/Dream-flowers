## ⚙️ Setup Instructions

1. सभी फाइलों को एक ही Project Folder में रखें।

2. Images को `images/` Folder में रखें।

3. Firebase इस्तेमाल करने के लिए:
   - Firebase Project बनाएं।
   - Firebase Config को `firebase.js` में डालें।

4. Website चलाने के लिए:
   - `index.html` Open करें।
